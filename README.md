# 두두런 (Dudu Run)

트릭컬(Tricaltree)의 캐릭터 **두두**가 주인공인, 크롬 오프라인 공룡 게임을 따라 만든 토이 프로젝트입니다.

플레이: https://kimdj7105.github.io/Dudu_run/

## 안내

- 재미로 만든 토이 프로젝트입니다. 상업적 목적이 없습니다.
- 사용된 트릭컬(두두) 관련 에셋의 저작권은 **EPID GAMES**에 있습니다.

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

- 점프: 스페이스바 / ↑ / W (오래 누를수록 높이 뜀)
- 숙이기: ↓ / S
- 시작/재시작: 스페이스바 (또는 클릭)
